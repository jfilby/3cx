# Instructions

## Project

This is 3cx which is 3code (https://github.com/capocasa/3code) plus an
easy-to-use TUI. Both are written in Nim.

The Nimble package name, and the binary to build is '3cx'.


## Nim libraries

Use illwill (https://github.com/johnnovak/illwill) for the TUI.


## TUI rules

- Use the / prefix to indicate a command.
- Ctrl-C is to cancel the current op.
- Ctrl-D is to exit the program.
- Text should be selectable by the mouse, and copied to the clipboard once
selected.
